# Task 2: Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a dataset containing 100 quotes and their authors. Python and Pandas are used to understand the dataset's structure, quality, and patterns.

## Objectives
- Understand the dataset structure.
- Identify missing values and duplicate records.
- Analyze quote lengths.
- Explore the distribution of authors.
- Present findings through an HTML dashboard and report.

## Technologies Used
- Python
- Pandas
- CSV
- HTML and CSS

## Tasks Performed
- Loaded and inspected the dataset.
- Checked missing values and duplicate records.
- Calculated average, minimum, and maximum quote lengths.
- Identified the top five authors by quote count.
- Created an HTML dashboard.
- Generated an EDA insights report.

## Key Findings
- Total quotes analyzed: 100
- Unique authors: 50
- Missing values: 0
- Duplicate rows: 0
- Average quote length: 122.27 characters
- Shortest quote: 34 characters
- Longest quote: 1084 characters

## Project Files
- `EDA.py` — EDA analysis script

- `eda_dashboard.py` — Dashboard generation script
- `eda_dashboard.html` — Interactive HTML dashboard
- `eda_insights_report.py` — Report generation script
- `eda_insights_report.txt` — Summary of findings
- `scraped_data.csv` — Input dataset
